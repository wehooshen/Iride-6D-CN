# EOS 6D 实机测试清单

一份可在室内完成的逐项勾选清单，用于在出门拍星前提前排查问题。
预计耗时：约 40 分钟。准备：满电电池、至少 2 GB 可用空间的 SD 卡、一支 AF 镜头（变焦头更佳）。

如遇异常：**切勿**格式化 SD 卡。拔插电池恢复后，请保留以下信息便于排查：

- `ML/LOGS` 整个文件夹（尤其是 `IRIDE.CSV`、`IRIDEBEN.TXT` 及可能存在的 `CRASH*.LOG`）
- 故障界面照片
- 下方对应的测试条目编号

单项未通过（✗）不影响后续项目：做好标记继续测试即可。

---

## 0. 准备阶段

- [ ] 佳能机身固件为 **1.1.6**（菜单 ⚙ → 固件版本）
- [ ] SD 卡包含：`autoexec.bin`、`ML/modules/iride.mo`、`ML/SETTINGS/IRIDE.EN`
- [ ] 模式转盘切至 **M 档**，照片风格为 **标准**，白平衡 **AWB**：记下当前 ISO 与快门，第 9 步需核对

## 1. 启动与全屏模式（1.4+ 定制核心）

- [ ] 开机后 1–2 秒内自动进入 Iride，并播放启动动画
- [ ] Iride 界面后方**无佳能原生菜单闪烁穿透**（按住方向键 5 秒同样无闪烁）
- [ ] 动画流畅（胶卷架左右滚动无明显卡顿）
- [ ] 在任意页面静止 1 分钟，机身**不会**自动熄屏或跳回佳能菜单
- [ ] 在主页按 MENU 退出 Iride，正常返回拍摄界面
- [ ] 拍摄界面按删除键重新打开 Iride；在 Iride 内按删除键进入 Magic Lantern 菜单，再按一次返回 Iride

## 2. 按键与快捷入口

- [ ] 选项 → 按键诊断：逐个按下方向键、SET、Q、INFO、MENU、PLAY、拨盘，均正常显示在列表中
- [ ] 手动按键时“finto（模拟键）”列保持空白
- [ ] 开启「SET 快捷白平衡」后，拍摄界面按 SET 直接打开白平衡界面，按 MENU 关闭

## 3. 实时取景切换（Live View）

开始本节前请先删除卡上旧的 `ML/LOGS/IRIDELV.TXT`（如有），Iride 会完整记录本次 Live View 状态流转。

- [ ] 胶卷 → 装入 Portra 400 → 按 START/STOP：Iride 关闭且实时取景**保持开启**（提示按 START/STOP 返回）
- [ ] 在实时取景中拍一张照片，再按 START/STOP：实时取景关闭并**自动回到胶卷页**
- [ ] 更换胶卷（Ektar 100）后再次按 START/STOP：**不会**出现 Live View 与胶卷架来回死循环
- [ ] 天文 → 星点对焦 → 按 START/STOP：Iride 叠加在实时取景之上；半按快门、拍摄、再按 START/STOP 均正常返回

## 4. 胶卷模拟

- [ ] 装入 Portra 400（36 张）：机身 ISO、白平衡（5300 K）与照片风格（人像）同步更新
- [ ] 拍摄 2 张照片：计数变为 2/36，文件名为 `R001xxxx.JPG/CR2`
- [ ] 胶卷架按 Q → 暂停：恢复 6D 常规参数；再选恢复：重新应用胶片参数
- [ ] 关机再开机：胶卷仍处于装入状态且进度保持 2/36
- [ ] **我的自定胶片**：任选胶片按 SET → 「自定义版本」：调整反差与颗粒，保存配方卡；卡上生成 `ML/IRIDE/MIA1.TXT`
- [ ] 从「自定」分类装入该配方并试拍：ISO、白平衡与照片风格与设定一致

## 5. 配置方案

- [ ] Av 档下对「街拍」按 SET：加载 Av 档对应参数
- [ ] 使用最大光圈小于 f/2.8 的镜头加载「人像」：提示已自动贴合镜头最大光圈
- [ ] 按 INFO 保存自定义配置，重启相机后配置仍在

## 6. 摄影工具

- [ ] 实时取景工具：开启峰值对焦并在 Live View 中可见；关闭后消失
- [ ] HDR 包围曝光（3 张）：按一次快门连续拍摄 3 张不同曝光照片
- [ ] ND 减光镜：裸镜 1/60 + ND1000 = 16 秒，按 SET 正确设置机身快门

## 7. 天文摄影（白天盖上镜头盖即可测试）

- [ ] 银河曝光：24 mm f/2.8 下 NPF 计算约 12 秒，按应用正确设置快门
- [ ] 观星日历与银河指向正常打开并显示当晚数据
- [ ] 夜间红光主题：选项 → 界面主题 → 夜间 (红光)，**全部**天文页面（含拍月与银河指向）均呈红黑护眼配色
- [ ] 间隔拍摄：选银河预设，设 3 张 × 5 秒启动，正常拍完 3/3 并发出双提示音
- [ ] 卡上生成 `DCIM/100CANON/ISaammgg.CSV`，包含 3 行 LGHT 记录
- [ ] **拍后暗场建议**：拍完亮场重开 Iride，弹出暗场拍摄建议；盖镜头盖按 SET 可用相同曝光与 ISO 拍摄暗场
- [ ] **长曝降噪提醒**：在佳能菜单开启“长时间曝光降噪”，再启动 2 张 × 5 秒间隔拍摄：Iride 发出提示；测完后请关闭该选项
- [ ] 拍摄中途按删除键可正常中止序列

## 8. 语言切换与 6D 自检

- [ ] 选项 → 语言 / Language：在 **简体中文 / English / italiano** 之间切换，菜单、帮助与胶卷说明均无乱码、无裁切
- [ ] 选项 → 6D 机身自检 → 按 SET：顺利跑完且无卡死
- [ ] 卡上生成 `ML/LOGS/IRIDEBEN.TXT`

## 9. 恢复 6D 默认

- [ ] 主页 → 恢复 6D 默认 → 按 SET：照片风格、白平衡、ISO 与快门均恢复至第 0 步记录的原值
- [ ] 当前胶卷自动暂停，文件名恢复 `IMG_xxxx`
- [ ] 检查 Magic Lantern 菜单：无残留开启的 Dual ISO、ETTR 或峰值对焦

## 10. 断电与数据安全

- [ ] Iride 打开状态下打开存储卡仓盖：机身干净关机，重启后胶卷与配置无损坏
- [ ] 开机状态下直接拔出电池：重启后 Iride 可正常启动（必要时自动从 `IRIDE.BAK` 恢复）
