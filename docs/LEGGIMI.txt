IRIDE 6D 1.6（简体中文版）—— 适用于 Canon EOS 6D（佳能原厂固件 1.1.6）
========================================================================

基于 Magic Lantern 6D 1.1.6 官方构建（2025-06-20，commit ed3e7c0），
内置面向 Iride 定制的核心补丁（模块全屏模式：防止佳能原生界面重绘覆盖、
实时取景下自动保活对话框、无固定延迟秒开）与 Iride 模块。
已预启用模块：iride、autoexpo、deflick、dual_iso、ettr、silent。

注意事项
--------
- 本软件为实验性质。已在实机 6D 上验证胶卷模拟与文件前缀，其余功能通过
  同源模拟器（211+ 项测试）并对照 astropy 验证天文算法。
- Magic Lantern（含本定制版）仅从 SD 卡运行，不修改相机内部 ROM：
  换上普通 SD 卡即可恢复原厂 6D。
- 若相机发生卡死：取出并重新装入电池即可恢复。


安装步骤（机身须为佳能原厂固件 1.1.6，参考 builds.magiclantern.fm/6D.html）
----------------------------------------------------------------------
1. 在 EOS 6D 机身内格式化 SD 卡。
2. 将本压缩包内的所有文件复制到 SD 卡根目录。
3. 将模式转盘切至 M 档，进入 菜单 > 扳手图标 > 固件版本 > 更新：
   启动 Magic Lantern 安装程序，按提示完成并重启相机。


打开与操作 IRIDE
----------------
- 开机启动：Magic Lantern 就绪后（约 1 秒）自动进入 Iride 主页
  （可在 选项 > 开机自动打开 中关闭）。若开机时按住半按快门准备抢拍，
  则不会弹出；任意时候半按快门均可立即关闭界面进入拍摄。
- 拍摄界面按【删除键（垃圾桶）】：打开 Iride（可在 选项 > 删除键打开 Iride
  中关闭，关闭后删除键恢复为直接打开 Magic Lantern 菜单）。
- 在 Iride 内按【删除键】：进入 Magic Lantern 原生菜单，再按一次关闭。
- 顶屏背光键：默认启用，但部分 6D 拍摄状态下可能不上报该键值，
  可在 选项 > 按键诊断 中实测验证。
- 拍摄界面按【SET】：快速打开 Iride 白平衡（补齐 6D 缺失的独立 WB 键）。
  需先在 选项 > SET 快捷白平衡 中开启；按 MENU 或选“完成”返回拍摄。
- 从 Magic Lantern 菜单进入：Shoot 分页 > Iride > 按 SET。

方向键 / 拨盘移动选择，SET 确认，MENU 返回上级。
底部常驻按键提示；任意页面按 INFO 查看中文帮助（配置方案页 INFO 为保存），
按任意键关闭帮助。


功能一览
--------
主页        天文、摄影、胶卷、恢复 6D 默认、配置方案、选项。
            右上角橙色圆点 = 存在可一键还原的 Iride 改动。
            在天文与摄影列表中，右侧实时显示所选功能说明与当前状态
            （绿点 = 已开启）。顶部显示当前页面路径。

天文        银河曝光 (NPF 法则)：按焦距、光圈与天区赤纬计算星点不拖线的
              最长曝光时间，按 SET 一键设置快门、光圈、ISO 与 3900K 白平衡。
            间隔定时拍摄：内置银河、深空、星轨、延时、日转夜（需实时取景+M 档，
              调用 ML autoexpo 与 deflicker）、暗场、平场、偏置场预设。
              按删除键停止。右侧显示总耗时、结束时间、剩余电量与存储空间；
              电量低于 5% 或卡满时禁止启动，拍摄中降至 4% 或卡满自动停止。
              静音快门：不抬反光板拍 DNG（0.3-30 秒，无 EXIF，需启用 silent）。
              抖动偏移：每隔若干张暂停，方便手动微调赤道仪。
              拍摄日志：在照片目录生成 ISaammgg.CSV（按夜分文件，次日中午切分），
              供 AstroStack 自动匹配暗场与选片。
              拍后暗场建议：亮场结束后重开 Iride，自动提示以相同快门/ISO/温度拍暗场。
              长曝降噪提醒：若佳能机身开启了长曝降噪（耗时翻倍），发出三声提示音提醒关闭。
            星点对焦：按 START/STOP 开启实时取景，SET 切换 x5/x10 放大，
              左右键微调焦点；实时显示 HFR（越小越清晰）。
              按 Q 启动 V 型曲线自动对焦（镜头须处于 AF），按任意键中止。
            极轴校准：显示北极星在极轴望远镜中的时钟方位（SET/左右切换肉眼或倒像），
              附带北斗七星与仙后座北天星图。
            观星日历：未来 7 晚月相、天文黑夜、无月时段、银河窗口与每周最佳夜，
              按 SET 跳转查看当晚银河指向。
            银河指向：逐半小时查看银心方位角、仰角与银河拱桥倾角。
            拍月曝光：结合月相与仰角的 Looney 11 法则，支持月面与地球照，
              按 SET 一键应用参数。
            文件前缀：将 IMG_ 改为 LGHT / DARK / FLAT / BIAS 便于后期堆栈。

摄影        HDR 包围曝光、景深合成（实时取景 + AF）、双原生 ISO、自动向右曝光 (ETTR)、
            移动侦测与陷阱对焦、实时取景工具（峰值、斑马纹、直方图、伪色、放大、
            点测光及暗光提亮 1-6 档）、ND 减光镜（30 秒内设快门，超过自动 B 门）、
            独立白平衡（佳能预设 + 2500-10000K 色温标尺，步进 100K，主拨盘 500K）。

胶卷        内置 16 款经典胶片，每款附带特性与适用场景说明。
            按 SET 装卷（可选 12/24/36 张、-2 至 +3 档迫冲/减冲）。
            已装卷时按 Q：暂停（恢复 6D 常规拍摄）/ 恢复 / 倒卷。
            胶片色调仅作用于机身 JPEG，RAW 保持中性；若处于纯 RAW 模式，
            Iride 会标红提示切换为 RAW+L 或使用配套电脑 XMP 预设。
            我的自定胶片（“自定”分类，最多 4 个）：任选胶片按 SET > “自定义版本”，
            可调 ISO、照片风格、反差、饱和度、色调、白平衡、颗粒与暗角（后两项用于电脑预设），
            保存为 ML/IRIDE/MIA1.TXT（至 MIA4.TXT）可拷贝分享给好友。

电脑预设    项目 presets 目录提供 16 套 Lightroom / LightCraft XMP 预设，
            让 RAW 照片获得与机身一致的胶片质感。

配置方案    5 个配置槽：INFO 保存当前设置、SET 加载、Q 删除、左右键改名。
            首次启动预置 5 套方案：人像、风光、街拍、运动、夜景。
            若镜头最大/最小光圈未达预设，将自动贴合镜头实际极限。

恢复 6D 默认 一键还原所有被 Iride 修改的设置（照片风格、ISO、快门、光圈、
            白平衡、回放、ML 开关、文件前缀），当前胶卷自动暂停不丢失进度。

选项        界面主题（常规 / 夜间红光 / 仅天文页红光）、动画效果、启动画面、
            开机自动打开、删除键打开 Iride、顶屏背光键、SET 快捷白平衡、
            装卷回放、过片提醒、地点（57 座城市或自定经纬度）、时区（支持自动夏令时）、
            本地暗度、按键诊断（ML/LOGS/IRIDEKEY.TXT）、6D 机身自检（ML/LOGS/IRIDEBEN.TXT）、
            语言 / Language（简体中文 / English / italiano）。

在 Iride 内按 START/STOP：关闭 Iride 并保持实时取景便于构图拍摄；
再次按 START/STOP：关闭实时取景并自动回到之前的 Iride 页面（星点对焦页除外）。

相关文件位置：
- 实时取景日志：ML/LOGS/IRIDELV.TXT
- 胶卷/天文/警告记录：ML/LOGS/IRIDE.CSV
- Iride 持久化状态：ML/SETTINGS/IRIDE.DAT（删除即重置）


首次室内自检（推荐）
--------------------
完整检查清单见 PROVA_6D.txt（约 40 分钟）。快速验证：
1. 按删除键打开 Iride，再按一次确认能进入 ML 菜单。
2. 配置方案：Av 档加载「街拍」，再按 INFO 保存自己的设置。
3. 胶卷：装入 Portra 400 拍 2 张，按 Q 体验暂停与恢复。
4. 摄影 > 实时取景工具：开启峰值对焦并在实时取景中确认生效。
5. 天文 > 观星日历与极轴校准。
6. 主页 > 恢复 6D 默认 > 按 SET：确认全部参数恢复原状。


升级与卸载
----------
升级：覆盖 SD 卡上的 autoexec.bin 与 ML/modules/iride.mo 即可，
胶卷进度与配置方案保存在 ML/SETTINGS/IRIDE.DAT 不会丢失。
卸载：在 菜单 > 固件版本 > 更新 中按 Magic Lantern 提示清除引导标记，
或直接更换不含 ML 的普通 SD 卡。
